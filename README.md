# 🙋 Mugisha David — Portfolio

A modern, production-ready full-stack **developer portfolio** built with **React, Vite, Tailwind CSS, Three.js, and Framer Motion**. Features 3D animations, a responsive layout, and a smooth user experience.

## 🌐 Live Site

👉 **[https://mugisha-david.vercel.app](https://mugisha-david.vercel.app)**

## ✨ Features

- 3D animated hero scene (Three.js)
- Smooth scroll animations (Framer Motion)
- Fully responsive design
- Projects showcase
- Resume section with Education & Skills tabs
- About, Services, Contact, and Footer sections

## 🛠 Tech Stack

- **React 18**
- **Vite**
- **Tailwind CSS**
- **Three.js**
- **Framer Motion**

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Production build
npm run build

# Lint
npm run lint
```

## 📦 Deployment

Deployed on **Vercel** — every push to `main` triggers a production deployment.
